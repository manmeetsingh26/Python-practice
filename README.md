## 🚀 Completed Programs

### 👤 User Information Program
Collects and displays basic user details.

### 🧮 Simple Calculator
Performs addition, subtraction, multiplication, and division.

### 🔢 Even Odd Checker
Checks whether a number is even or odd.

### 🎯 Number Guessing Game
Generates a random number and allows the user to guess it.

### 🎓 Student Grade Calculator
Calculates grades based on marks entered by the user.

### 🔐 Password Generator
Generates random passwords using letters, numbers, and symbols.

### 🌡 Temperature Converter
Converts temperatures between Celsius and Fahrenheit.
